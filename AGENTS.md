# Agent notes

This sample is deliberately unbranded. It uses a plain system-font stylesheet
so a partner can read the OAuth flow without mistaking the page for Jetlog's
own product. Do not add Jetlog colours, the logo, the wordmark or the B612
Mono font here.

Text that a pilot or partner reads follows the Jetlog voice: plain statements,
sentence case, no emoji, no exclamation marks, exact terms. Times are UTC.

Maintainers: Jetlog's own look and copy rules live in the Jetlog Design System
(the `jetlog-design` skill), which is not public.
